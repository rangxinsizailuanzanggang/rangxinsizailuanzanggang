# My Persona Vault

> 跨 AI 可迁移的个人知识库：知识、习惯、偏好、项目、技能、成果的唯一真值源。
> 任何 Agent（Claude Code / Cursor / Gemini 等）加载本仓库，即可对齐我的背景与工作方式。

## 设计原则

1. **源文件全部是 Markdown**，Git 为唯一真值，不绑定任何平台的私有格式
2. **档案与工作记忆分离**：`USER_PROFILE.md` 是稳定的"我是谁"，其余目录是持续沉淀的素材
3. **原子化卡片**：一个项目 / 一项技能 / 一条经验只写一次，靠链接和索引关联，不维护多份副本
4. **整体可迁移**：复制整个仓库即完成搬家，换 AI 不重新教一遍

## 目录说明

| 目录 | 用途 |
| --- | --- |
| `USER_PROFILE.md` | 核心档案：沟通偏好、输出规范、习惯、禁忌（跨 AI 最先读取） |
| `profile/` | 个人基础信息、技能栈、习惯与偏好 |
| `knowledge/` | 领域知识、学习笔记、复盘、踩坑经验 |
| `projects/` | 项目原子卡片：背景、方案、成果、指标、取舍 |
| `artifacts/` | 作品集与产出物索引（存链接和摘要，不放大文件） |
| `schema/` | 各类卡片的 frontmatter 模板与字段规范 |
| `index/` | 总索引、快照与迁移校验清单 |

## 给 AI 的读取规则

- 先读 `USER_PROFILE.md` 对齐偏好与约束，再按需检索其他目录
- 只引用仓库中真实存在的内容，**禁止编造**未记录的经历、技能或数据
- 输出格式与命名规范遵循 `profile/habits/` 中的约定
